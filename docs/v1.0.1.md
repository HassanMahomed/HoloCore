# HoloCore v1.0.1

HoloCore v1.0.1 completes the native Windows uninstall experience.

## Windows integration

- Registers HoloCore under **Windows Settings → Apps → Installed apps**.
- Adds a dedicated **Uninstall HoloCore** Start menu shortcut.
- Adds an uninstall action inside HoloCore Setup.
- Provides a native confirmation, progress, completion, and error window.
- Supports a quiet uninstall entry for managed Windows removal.

## Preservation contract

Uninstall removes only HoloCore application files and HoloCore-owned Windows integration. HoloCore Home, Knowledge, Code Maps, Memories, chat history, and connected project folders are preserved.

## Release verification

The release workflow builds and opens both the setup and uninstall interfaces, verifies the exact packaged version, and runs the install, upgrade, rollback, uninstall, and data-preservation lifecycle before publication.
