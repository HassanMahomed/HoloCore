# HoloCore v0.16.0

HoloCore v0.16 makes the Code Map more useful for understanding feature areas instead of treating an entire connected project as one cluster.

## What changed

- Code Map search stores normalized semantic terms and splits CamelCase names, so plain queries such as `integrity gate` match symbols such as `ReleaseIntegrityGate`.
- Clusters now use deterministic weighted modular communities. Strong `contains`, method, call, inheritance, and import relationships shape communities without collapsing every connected file into one group.
- Every community includes stable topics, key files, representative symbols, relationship counts, relation types, and exact mapped signals.
- Atlas refresh generates a Markdown community index and one evidence-backed note per community in the Code Map's generated `communities` folder (`holocore-out/communities` for a standalone Atlas, or the selected Home's project Code Map folder in a configured HoloCore World).
- Generated community notes include the Code Map source digest and remain outside curated Knowledge, preventing generated output from becoming its own source evidence.
- The Code Map report now lists community topics and relationship counts.

## Release boundary

This is a source milestone. Final Windows executables remain deferred until HoloCore reaches the stable release gate.

## Compatibility

The plain `code-map-groups` interface returns richer community metadata while retaining stable IDs, labels, sizes, signal IDs, relations, and signals. The older `atlas-constellations` name remains a compatibility alias.
