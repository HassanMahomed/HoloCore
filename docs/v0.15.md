# HoloCore v0.15.0

HoloCore v0.15 makes first installation a native Windows experience instead of a terminal-led workflow.

## What changed

- A four-step **HoloCore Setup** desktop application selects the Second Brain folder, first project, AI client connections, Code Map creation, update checks, and an optional installed Ollama model.
- Client and model detection runs in the background while the window remains usable.
- A review screen shows planned actions and exact resolved storage paths before installation.
- The checksummed `holocore-setup-windows-x64.exe` carries the engine inside itself, installs it per user, updates user PATH, creates a Start menu shortcut, and opens visual setup.
- `holocore-setup` provides the same native interface for developer and `uv` installations.
- `-Yes` and `-NoUI` preserve unattended and terminal-only deployment paths.
- GitHub-facing installation text and screenshots now show the native application.

## Release boundary

The source, tests, installer contract, and release workflow are prepared during development. Final `.exe` artifacts are generated only after v0.15 is declared stable and tagged.

## Safety and privacy

- Folder, client, and model discovery is read-only until the final Install action.
- HoloCore preserves unrelated AI client settings.
- Local-model discovery remains loopback-only and never installs or downloads a model.
- The setup application loads no remote UI assets and does not upload project content.
