# HoloCore v0.13.0

HoloCore v0.13 extends local Agent Activity capture to Cursor, Gemini CLI, and OpenCode.

## What changed

- Cursor hooks record completed tool use, tool failures, file edits, subagent completion, and agent stops.
- Gemini CLI hooks record completed tools, agent turns, and session ends.
- OpenCode's local plugin records tool completions and selected session events.
- Each event is normalized into an Agent Run, Action, and affected Item when a file path is provided.
- Existing MCP connections and user hook settings are preserved during setup and update reconciliation.

## Privacy

These new integrations record activity only. They do not ingest prompts, assistant replies, or transcripts into Chat History. The ledger stores a limited allowlist of event metadata and affected paths, not tool input or output bodies. Hook execution is observational and does not install permission or action-blocking handlers.

Claude Code and Codex retain their existing activity and chat-history behavior.
