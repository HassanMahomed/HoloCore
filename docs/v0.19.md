# HoloCore v0.19.0

HoloCore v0.19 completed the plain-language migration and prepared the v1 release supply chain.

## Highlights

- Moved the primary memory implementation to `memories.py`, `memory_collection.py`, and `memory_retrieval.py` while keeping thin compatibility import shims.
- Replaced new generated `animus-*` and `atlas-*` interfaces with `memory-*` and `code-map-*` names.
- Added schema-v6 project configuration using the `memories` field while continuing to read legacy `animus` configuration.
- Added whole-installation regeneration through `holocore sync-all --regenerate`.
- Added mandatory Authenticode verification for stable tagged releases, reproducible CycloneDX SBOM generation, and GitHub build provenance.
- Added signed install, upgrade, rollback, uninstall, native UI, and data-preservation release gates.
