# HoloCore v1.1.0

HoloCore 1.1.0 brings the desktop Control Centre and local recovery tools into the stable release line.

## What ships

- **One desktop Control Centre** for project selection, Knowledge, Memories, Code Map, AI connections, and storage status. First-run Setup and ongoing project management are available from the same application.
- **Connection visibility** that reports configuration, a user-run connection test, and last recorded activity separately.
- **Home backup and recovery** with portable ZIP exports, checksummed restore previews, safety backups, scheduled backups, and restore validation.
- **SQLite reliability improvements** for connection reuse, clearer lock failures, passive WAL checkpointing after capture, and resumable legacy database merges.
- **HoloCore Board for Obsidian**, a local read-only view of project activity, sessions, memories, and changed files, installed per vault by Setup.
- **Windows lifecycle improvements** including a graphical uninstaller and the existing recoverable install and upgrade path.

## Windows installation

PowerShell remains the primary installation method:

```powershell
irm https://github.com/HassanMahomed/HoloCore/releases/latest/download/install.ps1 | iex
```

The standalone Setup EXE is an alternative for users who prefer a guided download. This community build is unsigned and may show a Windows publisher warning. Checksums, an SBOM, and GitHub build provenance accompany the release.

## Not included in this release

Conversation search and deletion with an impact preview, interactive duplicate/conflict/staleness review, task-specific context packs, incremental processing controls, and performance/retrieval-quality measurements remain on the v1.2 roadmap. See the [roadmap](roadmap.md) for the planned sequence.
