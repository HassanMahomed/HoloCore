# HoloCore v0.14.0

HoloCore v0.14 adds optional local-model discovery and configuration without changing the keyless baseline.

## What changed

- `holocore models discover` safely checks Ollama on loopback and lists installed models.
- `holocore models configure` explicitly selects one installed model for the shared HoloCore Home.
- `holocore models status` and ordinary project status show the active mode, model, reachability, and fallback.
- `holocore models clear` removes only the Home-level selection and returns to deterministic extraction.
- Matching MCP tools expose the same read/write boundary.
- Configured provider failures, timeouts, and invalid structured output fall back to deterministic extraction while preserving raw audits and sanitized provenance.

## Safety and privacy

- Discovery never scans the LAN or public internet; only credential-free HTTP loopback endpoints are accepted.
- HoloCore does not install Ollama, start services, or download/delete models.
- The Home selection stores provider, endpoint, model name, and update time only. It stores no credentials, prompts, responses, or project content.
- Environment variables and compatible legacy provider settings remain supported.

The full baseline remains usable without Ollama, a model download, an API key, or network access.
