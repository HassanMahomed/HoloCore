# HoloCore v0.12.0

HoloCore Home now uses plain folder names:

- `Knowledge/Projects/<project-id>` stores project knowledge.
- `Projects/<project-id>/CodeMap` stores each project's structural map.
- `Memories/ChatHistory/<project-id>` stores original chat audits.
- `Memories/animus.db` remains the shared memory and activity database.
- `worlds.json` remains the project registry at the Home root.

Fresh Homes use this layout automatically. Existing Homes can preview and apply an in-place migration with `holocore migrate-layout` and `holocore migrate-layout --apply`. Old folder paths remain available through junctions where supported, so older HoloCore versions and existing Second Brain links can continue to resolve.

The migration refuses to merge an existing old folder with a conflicting new folder, checks the SQLite database, and writes a migration journal. Routine package upgrades do not rename personal folders automatically.
