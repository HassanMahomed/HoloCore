# HoloCore v0.17.0

HoloCore v0.17 turns Memories and cross-source investigation into complete user-facing workflows.

## Memories workspace

- Search retained Memories by text.
- Filter by memory group and a partial provenance source path or name.
- Browse recent records in bounded pages rather than loading the entire database.
- Inspect creation and update times, routing hints, transformations, privacy metadata, general metadata, and every recorded source reference.
- Review the tracked memory timeline beside retained records.
- Explicitly forget one project-scoped memory and its stored provenance. Original source files are never deleted.

## Research and architecture workflows

- Build a Research brief or Architecture brief from one question in the Console.
- Use the same read-only workflows through `holocore research`, `holocore architecture`, and matching MCP tools.
- Combine bounded evidence from Code Map items and their immediate relationships, verified Knowledge notes, and optionally scoped Memories.
- Show source counts, evidence locations, confidence labels, missing evidence categories, and concrete next steps.
- Keep generated briefs transient until the user explicitly selects **Save reviewed brief to Knowledge**.

## Interface and accessibility

- The Console uses high-contrast controls, visible keyboard focus, labeled fields, responsive layouts, live status regions, and reduced-motion support.
- Destructive memory deletion requires an explicit confirmation and explains that original sources remain intact.

## Plain integration names

- New integrations advertise `memory-*` and `code-map-*` commands and MCP tools.
- Older `animus-*` and `atlas-*` names remain callable only as compatibility aliases.
- Existing installations can run `holocore sync-all --regenerate` to rebuild every HoloCore-owned command and skill with the new names and remove obsolete generated legacy files.
- Regeneration preserves unrelated client settings and user-authored commands.

## Release boundary

This is a source milestone. Final Windows executables remain deferred until HoloCore reaches the v1.0 stable release gate.
