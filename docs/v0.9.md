# HoloCore v0.9

Version 0.9 turns HoloCore's installation, memory, and activity foundations into a simpler daily product.

## What changed

- **Impact lookup:** `holocore activity affected <item>` shows which agents and actions touched a file or directory.
- **Agent handoff:** `holocore handoff [run-id]` gives the next agent a bounded summary of work, failures, and affected items without replaying a whole conversation.
- **Connection health:** `holocore connections` distinguishes an installed AI app from a valid HoloCore MCP connection for Claude, Codex, Cursor, Gemini, and OpenCode.
- **Simpler Console:** Agent Runs can be filtered by agent, action, status, tool, or affected item, and Maintenance shows connection health.
- **Upgrade reconciliation:** setup and upgrade results include connection status, and every upgrade rescans for AI apps installed since the previous HoloCore version.
- **Lightweight automatic updates:** the optional updater still checks at most once per day during real HoloCore activity. It does not install a resident process or Windows Scheduled Task.

## Install or upgrade

```powershell
irm https://raw.githubusercontent.com/HassanMahomed/HoloCore/main/install.ps1 | iex
```

Then verify the environment:

```powershell
holocore connections
holocore status
holocore auto-update --enable   # optional
```

Existing projects, Home data, legacy CLI names, MCP tools, and internal storage names remain compatible.

## Privacy

Impact lookup and handoffs use only the structured activity ledger. The ledger does not retain prompt bodies, assistant replies, complete tool inputs or outputs, credentials, cookies, tokens, or authorization values.
