# HoloCore v0.10 — Agent Handoffs

HoloCore v0.10 turns the existing run summary into work that can pass safely between agents.

## What is included

- Create a persistent handoff linked to a recorded agent run.
- List open, claimed, completed, and abandoned work.
- Atomically claim open work so two agents cannot both take it.
- Return sanitized run context when a handoff is claimed.
- Complete work by the agent that claimed it, or abandon work that should not continue.
- Use the same lifecycle from the CLI and MCP.

The existing `holocore handoff [run-id]` command remains a read-only run summary. Persistent work uses `holocore handoffs`:

```powershell
holocore handoffs create <run-id> --title "Continue the release" --note "Review the pending packaging task."
holocore handoffs list --status open
holocore handoffs claim <handoff-id> --agent claude
holocore handoffs complete <handoff-id> --agent claude --reason "Packaging task finished."
```

Handoff records stay in HoloCore's existing local activity database. The stored note is limited to 2,000 characters; it is user-authored and should not contain credentials or private conversation text. Agent context is generated when claimed from the sanitized run/action/item records.
