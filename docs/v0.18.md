# HoloCore v0.18.0

HoloCore v0.18 focused on recoverability and the native Windows lifecycle.

## Highlights

- Added explicit Memories database migrations with automatic backup, integrity verification, rollback, and journaling.
- Added a resumable setup-operation journal for interrupted first-run configuration.
- Added the standalone native Windows setup application with folder selection, AI-client detection, feature choices, local-model detection, and a review-before-apply step.
- Added fail-closed release manifests and SHA-256 verification.
- Added native uninstall while preserving HoloCore Home and registered project data.
- Added built-artifact smoke tests to the Windows release workflow.
