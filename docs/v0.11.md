# HoloCore v0.11 — Clearer Console and Code Map

HoloCore v0.11 uses plain labels in the places people see most: the local Console, interactive code map, and current user documentation.

## What changed

- The Console calls saved prior-work context **Memories**, chat transcripts **Chat History**, and recorded tool use **Agent Activity**.
- The Console uses plain group names such as **Memory groups**, **Tracked changes**, and **Setup & Updates**.
- Storage paths in the Console are presented with readable labels.
- The interactive map calls graph nodes **items**, related groups **clusters**, and projects **projects**.
- The GitHub capability guide reflects current installation, connection, activity, handoff, and update behavior.
- The release metadata advances to `0.11.0`.

## Compatibility

This release changes user-facing labels only. Existing CLI commands, MCP tool and field names, database tables, storage folders, and generated client connections remain compatible. Technical names such as `Atlas`, `Animus`, `World`, `Signal`, and `Constellation` may still appear in APIs, data, or developer documentation.

## Release status

The v0.11 implementation and documentation are in progress. Publish a downloadable build after the release checks are complete.
